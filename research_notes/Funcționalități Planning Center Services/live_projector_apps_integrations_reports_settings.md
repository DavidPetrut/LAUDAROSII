Research date: 2026-10-12. All official UI labels are kept in English, in quotes, exactly as Planning Center names them. ## Key Question 1 — Services LIVE (running a plan in real time)

### Takeaway
Services LIVE is a real-time "run the order of service" view opened from a plan's "Order" tab via the "Share" icon → "Live" (or the keyboard shortcut `l`). Exactly one person at a time "takes control" and steps through items with "Prev"/"Next"; each "Next" records the actual start/end time of the item, which later feeds the "LIVE: Recorded times" plan report and the service type "Service Length" report (planned vs actual). Several display layouts exist for monitors (Normal, Countdown Full, Countdown Lower, Lower Third, Fullscreen Overview), there is a built-in LIVE chat, and it works on web and in the Services mobile app (with push notifications). The API exposes `Live`, `LiveController`, `toggle_control`, `go_to_next_item`, `go_to_previous_item`, `current_item_time`, `next_item_time`, `watchable_plans`.

### Cited Findings

**Purpose, where it lives, how to open it**
- Services LIVE lets teams "go through the order of service in real-time", communicate in chat and "plan ahead"; different display formats can be shown on monitors around the church (stage display, production booth). Team members can open LIVE from their scheduled plans. — [What is Services LIVE?](https://help.planningcenter.com/en/139479-what-is-services-live-.html)
- Desktop path: "Plans" → (folder) → service type → plan date → "Order" tab → "Share" icon (top right of the service order) → "Live". Mobile controllers: "Plans" (bottom nav) → folder → service type → plan date → three-dot icon (top right) → "Live". Scheduled viewers/viewers: open plan from "Plans" or "My Schedule" tab → "Order" tab → "Live" above the order of service. — [What is Services LIVE?](https://help.planningcenter.com/en/139479-what-is-services-live-.html)
- If you don't see the "Live" button, "you'll need someone with LIVE control permissions to start the session first." Users who can't control LIVE see its button only after a controller starts a session; if no one is controlling, they have no access. — [Services LIVE permissions](https://help.planningcenter.com/en/139480-services-live-permissions.html)
- Keyboard shortcut `l` = "Open Services LIVE" when viewing a plan. — [Use keyboard shortcuts in Services](https://help.planningcenter.com/en/144368-use-keyboard-shortcuts-in-services.html)
- The plan page "Share" menu offers "Services LIVE: Shares a real-time view of the plan, useful for tech booths or backstage monitors. Copy the URL from the LIVE view, or create a permalink to the closest LIVE view." The "Permalink" option has a first dropdown with types "Plan", "Public View", "Services Live" (requires plan and Services LIVE permissions) and a second dropdown "before today" / "after today" (organization timezone), plus "Copy link". — [Share your plan](https://help.planningcenter.com/en/139461-share-your-plan.html)
- On mobile (Services Mobile v6+): "Services Live" is always available in the main header (three-dot) menu; "On the day of the plan, if Live has already started or the user has permission to start it, a Live button appears with the Order actions, to the right of Play and Print." — [Changelog: Services Mobile Version 6 plan page](https://www.planningcenter.com/changelog/services/24502348291099-improved-an-optimized-plan-page-in-services-mobile-version-6)

**Who can control / view / chat (permission matrix)**
- Table "Who can use LIVE?": rows "Control LIVE", "Access chat", "View LIVE"; columns Administrator, Editor, Scheduler, Viewer, Scheduled viewer. "Control LIVE": ✓ (available by default) for Administrator and Editor; "*" ("Available depending on settings") for Scheduler, Viewer, Scheduled viewer. "Access chat": ✓ for Administrator, Editor, Scheduler, Viewer (not Scheduled viewer — "Only people with viewer permissions or higher can see the LIVE chat"). "View LIVE": ✓ for all five levels ("Anyone scheduled to the plan can view Services LIVE"). — [Services LIVE permissions](https://help.planningcenter.com/en/139480-services-live-permissions.html); same table on [What is Services LIVE?](https://help.planningcenter.com/en/139479-what-is-services-live-.html)
- "By default, only editors and administrators can control it. Service type settings can give control to other people." — [Services LIVE mobile](https://help.planningcenter.com/en/143028-services-live-mobile.html)
- Service type settings page → "Permissions" section: "Controls who can operate Services LIVE. Editors and administrators have control by default. 'Add' grants control to additional people." — [Manage service type settings](https://help.planningcenter.com/en/142848-manage-service-type-settings.html)
- In the full Services permission table, "Services LIVE" rows are: viewing LIVE (every level), controlling LIVE (asterisk for lower levels; standard for Editor and Administrator), "Taking control from someone else", "using LIVE chat", and "resetting LIVE times" (available only for teams the person leads). — [Permissions in Services](https://help.planningcenter.com/en/136863-permissions-in-services.html)
- API: `LiveController` = "A person who can control Services LIVE without the required permissions" (endpoint `/service_types/{service_type_id}/live_controllers`); attributes `created_at`, `full_name`, `photo_thumbnail_url`, `updated_at`; assignable on create/update `person_id`; include `person`. — [Services OpenAPI 2018-11-01](https://api.planningcenteronline.com/services/v2/open_api/2018-11-01)

**Control model (take control, Next/Prev, Start, release, take-over)**
- "Only one person can move between items at a time" and each move "updates every screen"; "Selecting Next records the actual time for each item in the LIVE report." The controller can release control so someone else can take it; "An administrator can take control from the dropdown." — [Services LIVE permissions](https://help.planningcenter.com/en/139480-services-live-permissions.html)
- Keyboard shortcuts inside LIVE: Next = up arrow, right arrow, page down, or space; Previous = down arrow, left arrow, page up, or shift + space. — [Services LIVE permissions](https://help.planningcenter.com/en/139480-services-live-permissions.html)
- Normal Layout control: "Select 'take control' to start controlling. Use the 'Start' arrow to begin the first item, then 'Prev' and 'Next' to move through items." On mobile: select "take control", then tap the left and right arrows to move between items. — [What is Services LIVE?](https://help.planningcenter.com/en/139479-what-is-services-live-.html)
- "Important: If the service order changes during a session, viewers see the change only after manually refreshing." — [What is Services LIVE?](https://help.planningcenter.com/en/139479-what-is-services-live-.html)
- API `Live` attributes: `can_chat` (bool), `can_control` (bool), `can_control_video_feed` (bool), `can_take_control` (bool), `chat_room_channel` (string), `dates` (string), `live_channel` (string), `series_title`, `title`. Includes: `controller`, `current_item_time`, `items`, `next_item_time`, `service_type`. Endpoints: `GET /service_types/{id}/plans/{plan_id}/live`, `GET/PATCH/DELETE .../live/{live_id}`, `POST .../live/{live_id}/toggle_control`, `POST .../live/{live_id}/go_to_next_item`, `POST .../live/{live_id}/go_to_previous_item`, `GET .../live/{live_id}/controller` (Person), `GET .../live/{live_id}/current_item_time` and `next_item_time` (ItemTime), `GET .../live/{live_id}/items`, `GET .../live/{live_id}/watchable_plans` (Plan), `GET .../live/{live_id}/service_type`. — [Services OpenAPI 2018-11-01](https://api.planningcenteronline.com/services/v2/open_api/2018-11-01)

**What the LIVE page shows (Normal Layout)**
- "The 'Normal Layout' suits production booths and cue callers. It's the only layout with chat." Elements: **Countdown** showing time left for the current item, with settings in a dropdown: "Full Item Length" (shows the item's full length, even if the service runs long), "End Item on Time" (keeps items in sync with simultaneous services), "End Service on Time" (helps the service end at a set time, e.g. parking-lot turnover). **Service order** left sidebar lists all items; selecting an item shows item notes and planned lengths; a "Time" dropdown switches between "Length", "Planned Time" and "Projected Time"; with multiple service times choose a time from the "[Time] Service" dropdown; "Yellow times are recorded; black times are projected and update as you move through the order." **Now/Next**: shows the current item's name and item notes in "Now" and the upcoming item in "Next". **Chat**: real-time team messaging. **"Services I'm Watching"**: eye icon at top right to see other concurrent services. — [What is Services LIVE?](https://help.planningcenter.com/en/139479-what-is-services-live-.html)
- Mobile layout: tap the arrow at the top right to open the menu; change the "Layout" or "Countdown" setting, or tap the moon icon for dark mode; Now/Next bars can be dragged to resize. — [What is Services LIVE?](https://help.planningcenter.com/en/139479-what-is-services-live-.html)
- Countdown Full layout notes "the estimated service end time"/"service end estimator at the bottom of the screen" and "The countdown modes don't change the service end estimator". — [Update Services LIVE displays](https://help.planningcenter.com/en/139483-update-services-live-displays.html)

**Display layouts for monitors/TVs**
- Layouts: "Normal layout" (default for controlling; shows the service order, chat, and more; "Change the view from the toolbar by hovering your mouse over the top of the screen"); "Countdown Full" (only the main countdown and the estimated service end time — confidence monitor for a speaker); "Countdown Lower" (smaller countdown in the lower left leaving room for video; "The background is green by default, so a live video mixer can replace it with your video" — e.g. nursery); "Lower Third" (same as Countdown Lower but shows current and next service items instead of a countdown — lobby/foyer displays); "Fullscreen Overview" (time left in the current item, what's next and the current time — backstage monitor). — [Update Services LIVE displays](https://help.planningcenter.com/en/139483-update-services-live-displays.html)
- The help center does not describe a dedicated Apple TV/TV app for LIVE; displays are browser windows/mobile app views placed on monitors. — [Update Services LIVE displays](https://help.planningcenter.com/en/139483-update-services-live-displays.html)

**LIVE chat**
- Chat tabs: "Organization-level chat" — the tab bearing your organization's name; anyone with chat access sees it regardless of service type; "Service type chats" — one tab per service type for people watching LIVE in that service type; watching several services opens a separate tab for each. — [Services LIVE permissions](https://help.planningcenter.com/en/139480-services-live-permissions.html)
- Mobile push notifications for LIVE chat: "Push notifications arrive when you leave the app or your screen is locked. Closing LIVE to view other Services content stops notifications." There is no separate notification toggle for LIVE. — [Services LIVE mobile](https://help.planningcenter.com/en/143028-services-live-mobile.html); [Manage mobile app notifications](https://help.planningcenter.com/en/143040-manage-mobile-app-notifications.html)

**Planned vs actual: data model and reporting after the service**
- API `ItemTime` attributes: `exclude` (bool), `length` (int), `length_offset` (int), `live_end_at`, `live_start_at`; assignable `exclude`, `plan_time_id`, `plan_id`; includes `item`, `plan_time`, `plan`. API `PlanTime` attributes include `starts_at` ("Planned start time."), `ends_at` ("Planned end time."), `live_starts_at` ("Start time as recorded by Services LIVE."), `live_ends_at` ("End time as recorded by Services LIVE."), `recorded` (bool), `time_type` (rehearsal | service | other), `team_reminders`. API `Item.length` (int, planned), `service_position` (`pre`/`post`/`during`); `Plan.total_length` = "The total of length of all items, excluding pre-service and post-service items." — [Services OpenAPI 2018-11-01](https://api.planningcenteronline.com/services/v2/open_api/2018-11-01)
- Plan report "LIVE: Recorded times": "Generated after a service to compare planned and actual lengths of service items." — [Create plan reports](https://help.planningcenter.com/en/139387-create-plan-reports.html)
- Service type reports → "Service Length" tab ("applies if you use Services LIVE"): top stats "Average planned service length, average actual service length, and the difference between them. The difference shows green if actual is under planned and red if it's over." Bar graph: hover over a plan to see how far its planned lengths differed from the LIVE times. Print icon only (no CSV). — [Create service type reports](https://help.planningcenter.com/en/139392-create-service-type-reports.html)
- ProPresenter can show a "Planning Center Live" timer object on a Stage screen with "Theme: Dark or Light" and "Time format": "Full Item Length" (default), "End Item on Time", "End Service on Time"; multiple timers per layout. — [Renewed Vision: Planning Center Live and Stage Timers](https://support.renewedvision.com/hc/en-us/articles/1500006143281)

### Inferences
- The three "Countdown" modes are the mechanism behind "running late/ahead": "Full Item Length" ignores drift, "End Item on Time" absorbs drift inside the current item, "End Service on Time" redistributes drift to keep the end time; the Normal Layout's "Projected Time" column (black) vs recorded (yellow) is the visible late/ahead indicator.
- There is no "Start service"/"End service" button pair; the service is started with the "Start" arrow (first item) and ends when the controller advances past the last item; actual times per item are stored per ItemTime (per service time), which is why reports can compare per time.
- `can_control_video_feed` on the Live resource suggests a video-feed control capability exists in the Live data model, but no help article describes a video feed UI.

### Gaps
- No official source lists an "End service"/"stop" control label, nor whether LIVE can be run simultaneously by different controllers for different service times of the same plan (the UI only shows a "[Time] Service" dropdown).
- No public documentation of the exact "LIVE: Recorded times" report columns or of a way to export recorded times to CSV.
- "Resetting LIVE times" is mentioned only in the permissions table; the UI path for resetting was not found.

## Key Question 2 — Projector (lyrics/slides projection)

### Takeaway
Planning Center Projector was an iPad-only app (launched April 2012) that presented lyrics and slides wirelessly from Services; Planning Center announced on 8 Feb 2018 that it would stop developing it, stopped charging users on 7 Feb 2018, supported it until 11 Feb 2019 and closed new sign-ups. It is **discontinued** in 2025–2026; the only vestiges are the `CustomSlide` resource (text slides attached to plan items), `Item.selected_background_id`/`selected_layout_id`, and the `Organization.projector_enabled` flag in the API. Churches now project via third-party integrations (ProPresenter, Proclaim, MediaShout, etc.).

### Cited Findings
- Projector was introduced in April 2012 as a Planning Center product. — [Introducing Planning Center Projector (blog, 2012)](https://www.planningcenter.com/blog/2012/04/introducing-planning-center-projector)
- "The end of Projector" (Jeff Berg, Feb 08, 2018): Projector was "an iPad-only app that helped churches present lyrics and slides wirelessly during services, with tight integration into Planning Center"; reasons: the mobile team had to pause work on Services and Music Stand to build it, and "most other presentation apps had added Planning Center integration". Timeline: current users no longer charged as of Feb 7, 2018; support continues through Feb 11, 2019; no future updates; new churches can no longer sign up; users advised not to update iOS. Recommended alternatives with offers: Proclaim (from $16.99/mo, 90-day trial code PCPROJECTOR), MediaShout ($269 one-time for Projector customers), ProPresenter (from $399 single license). — [The end of Projector](https://www.planningcenter.com/blog/the-end-of-projector)
- Third-party summary of the same: Projector "was built to show lyrics, slides, and video from a Planning Center Services plan". — [AirTurn blog: Planning Center Projector](https://www.airturn.com/blogs/apps/planning-center-projector)
- API remnants: `CustomSlide` — "A CustomSlide is used for adding text intended for display on a screen." Attributes: `body`, `enabled` (bool), `label`, `order` (int); assignable on create/update additionally `item_id`, `attachment_id`; includes `item`, `attachment`; endpoints `GET/POST /service_types/{id}/plans/{id}/items/{id}/custom_slides` and `GET/PATCH/DELETE .../custom_slides/{id}`. `Item` assignable attributes include `selected_attachment_id`, `selected_background_id`, `selected_layout_id` (relationships `selected_layout`, `selected_background`, `selected_attachment`). `Organization.projector_enabled` (bool) still exists. — [Services OpenAPI 2018-11-01](https://api.planningcenteronline.com/services/v2/open_api/2018-11-01)
- The current planningcenter.com "Integrations" directory lists ProPresenter (Third-party, Popular, Presentation) and no first-party projection product. — [Planning Center Integrations](https://www.planningcenter.com/integrations)

### Inferences
- A rebuild should treat "Projector" as out of scope for the 2025–2026 product; the only user-visible projection-ish features today are the "Lyrics & Chords" editor data (lyrics, sequences) consumed by ProPresenter/Proclaim/MediaShout via the API, and the `CustomSlide` text slides (which the web UI no longer surfaces prominently — no help article found).

### Gaps
- No 2025–2026 help article describes a UI for creating "custom slides" in Services; whether the web UI still exposes them is unknown.

## Key Question 3 — Mobile apps (Services app, Music Stand app, Church Center)

### Takeaway
Three apps matter: (1) **"Planning Center Services"** (iOS 18+/iPadOS 18+/visionOS 2+, Android; v6.11.x in Oct 2026, Liquid Glass redesign Sept 2026) with bottom tabs "Schedule", "Plans", "Songs", "Media", "People" and a tab-bar mini media player; it covers My Schedule (accept/decline/blockouts/signups/household), plan editing (Order/Teams/Times/Notes/Files tabs), scheduling people, chat, LIVE, the media player (List/Song/Lyrics/Docs/Notes tabs, loop, metronome, offline "Download playlist", CarPlay/Android Auto), printing reports, and "Login Settings". (2) **"Planning Center Music Stand"** is still a **separate** standalone iOS/Android (and Mac Apple-silicon/visionOS) app and a paid add-on to Services ("Add Music Stand ($5/month)" on the pricing page vs "price depends on the number of people in your Services subscription" in the help center); it has PDF/chord-chart viewing, annotations (pen/highlighter/text/eraser + 2026 fountain pen/watercolor/crayon), foot pedal/keyboard/MIDI, facial-gesture page turns (2025), metronome with Ableton Link sync, media player, page rearrangement, offline mode (last 10 plans), "Sessions", external display/AirPlay, dark mode. A "Web Music Stand" exists inside Services web. (3) **Church Center** app/web has only the volunteer "Me page" → "Schedule" subset (accept/decline, "More...", "Actions": accept all, add blockout, email leader, subscribe to calendar; household scheduling; chat) — no order of service, item details, teams, or rehearsal tools.

## Key Question 4 — Integrations

### Takeaway
Services integrates (a) natively with SongSelect, PraiseCharts, RehearsalMix and RehearsalPack/MultiTracks ("Song File Integrations"), CCLI auto-reporting, Planning Center Publishing (sermon episodes) and Zapier (triggers only for People/Giving — none for Services); (b) via its public JSON:API with third-party presentation software — ProPresenter (7.7+; 7 settings: plan-update checks, library matching, historical plans, arrangements from sequences, auto upload/download, download library; LIVE timers), MediaShout (V4–V6), Proclaim, and others; (c) via personal iCal/webcal feeds. Attachments can be uploaded, created (Lyrics & Chords, text doc, stage layout) or linked (URL, YouTube, Vimeo); Dropbox/Google Drive/Box and Ableton Live sets have no documented integration. The API's "Zoom" resource is unrelated to Zoom video — it stores a saved zoom level/offset for an attachment on a device.

### Takeaway
