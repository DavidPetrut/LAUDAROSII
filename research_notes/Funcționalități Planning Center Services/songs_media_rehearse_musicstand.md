## KQ1. Songs library — what a Song is, song fields, the Songs page (columns/filters/search), tags, usage history/reports, CCLI reporting, archiving, adding/importing songs, permissions, merging duplicates

### Takeaway
A Song is a thin header record (title, author, copyright, CCLI#, admin, themes, notes, hidden) that owns one or more Arrangements; nearly all musical content lives on the Arrangement and its Keys. The Songs page is a filterable list (Music / Content / Tags / History filter tabs, pinned filters, bulk edit, column chooser with "Expanded"/"Condensed" views) with an "Actions" menu that hosts "Edit Tags", "Song File Integrations", "CCLI Settings", "Manage Files", and a report icon with five song reports. There is no documented "merge duplicate songs" feature.

### Cited Findings

**Song data model (API `Song`)**
- `Song` attributes: `admin` (string), `author` (string), `ccli_number` (integer), `copyright` (string), `created_at`, `hidden` (boolean), `id`, `last_scheduled_at` (date_time), `last_scheduled_short_dates` (string), `notes` (string), `themes` (string), `title` (string — "Name of the song. On create, passing a CCLI number lets Services fetch the song metadata."), `updated_at`. Create/update-assignable: title, admin, author, copyright, ccli_number, hidden, themes. Action `assign_tags` (replaces the full tag set; 204 No Content). Edges: `arrangements`, `attachments`, `last_scheduled_item` (requires `?service_type=` param), `song_schedules` (filters `after`, `before`, `most_recent` with `amount`, `most_recent_with_upcoming`, `three_most_recent`), `tags`, `unscoped_arrangements` (includes archived). Order options: created_at, last_scheduled_at, title, updated_at. Query: `where[author]`, `where[ccli_number]`, `where[hidden]`, `where[themes]`, `where[title]`. — [API: song](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/song)
- `SongSchedule` (usage history record, read-only): `arrangement_name`, `key_name`, `plan_dates`, `plan_sort_date`, `plan_visible` (boolean), `service_type_name`; to-one relationships `arrangement`, `key`, `plan`, `service_type`, `item`; orderable by `plan_sort_date`. — [API: song_schedule](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/song_schedule)
- The CCLI# of a song is entered in the "Song Information" popup (the help text: "Before importing files, make sure the song has a CCLI# listed. The CCLI# is entered in the Song Information popup."). — [SongSelect® by CCLI integration (139448)](https://help.planningcenter.com/en/139448-songselect--by-ccli-integration.html)
- Changelog (CCLI auto-reporting, 2023) states CCLI numbers "are shown under the title on any Song's page and are often added automatically when you add songs"; songs added through the "All Songs" search "will always have a CCLI number". — [Auto reporting to CCLI changelog](https://www.planningcenter.com/changelog/services/18385749592603-new-auto-reporting-to-ccli)
- 2016 "new song pages" redesign (still the current structure): one main song page; "Song details stay in the header, and arrangements appear as side tabs"; an "All Arrangements" tab at the top applies files or tags to every arrangement; "Rarely used editing functions, such as detailed copyright info, move into an editing box"; inline editing ("click a field such as title or length and type. Enter or Tab saves"); "No Save button. Changes save automatically." — [The new song pages (blog, Aug 15 2016)](https://www.planningcenter.com/blog/-the-new-song-pages-html)

**Song & arrangement tags, tag groups**
- Two tag types: "Song tags" apply to the song regardless of arrangement (e.g. a Christmas song); "Arrangement tags" can differ per arrangement (e.g. fast vs slow). Create: "Songs" → "Actions" → "Edit Tags" → "Song" or "Arrangements" tab. Assign: on the song page, Tag section → "Add"; song tags at the top of the "All Arrangements" tab, arrangement tags at the bottom of a specific arrangement's tab; type a tag name or pick a tag group; "X" removes. You only see tags matching the tab you're on. Filter: "Filter" → "Tags" tab → "Tag" or "Tag Group". Bulk edit: pencil icon → "Bulk Edit Songs" or "Bulk Edit Arrangements" → check items → "Bulk Edit" → "Add Tags"/"Remove Tags" → "Update x Songs". Suggested tag groups: "Seasons" (Christmas, Easter, Patriotic; choose "None" to exclude), "Library"/"Ministry", "Leader". — [Song and arrangement tags (139436)](https://help.planningcenter.com/en/139436-song-and-arrangement-tags.html)
- Tag groups (shared Tags page for Songs/Media/People/Files): "Add Tag Group" with fields "Name", "Folder" (scope to a department folder), a multiple-selection checkbox ("more than one tag in the group can apply"), and a required behaviour (a new item "must have one of the group's tags selected at creation"). Tags are created in the "add tag" box + Enter; edit by clicking name; 🗑️ to delete. Requires people-and-plan administrator permissions. Enabling RehearsalMix auto-creates a file tag group. — [Manage tags in Services (142852)](https://help.planningcenter.com/en/142852-manage-tags-in-services.html)
- API `TagGroup`: `allow_multiple_selections` (bool), `name`, `required` (bool), `service_type_folder_name`, `tags_for` ∈ {`person`,`song`,`arrangement`,`media`}; edges `folder`, `tags`; filters arrangement/media/person/song. `Tag`: `id`, `name`, to-one `tag_group`; inbound edges from arrangement, media, person, song, tag_group, team_position. — [API: tag_group](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/tag_group), [API: tag](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/tag)

**Archiving ("Hidden") songs/arrangements**
- Archive a song: song page → "Actions" → "Archive song"; archive an arrangement: select it in the left sidebar → "Archive" button (top right). Restore: "Filter" → "History" tab → "Show Archived Songs" / "Show Archived Arrangements" → song → "Actions" → "Restore song" (arrangement: dropdown beside song title → arrangement → "Restore"). Bulk: ✏️ → "Bulk Edit Songs"/"Bulk Edit Arrangements" → check → "Bulk Edit" → "Archive" or "Restore" → "Update X Songs or Arrangements". Archived items are hidden from song scheduling, song filters and the Songs page unless filtered for, but still appear in plans where already scheduled. Files on archived songs still consume storage. Requires song editor or above; article advises against deleting. — [Archive and restore songs and arrangements (139431)](https://help.planningcenter.com/en/139431-archive-and-restore-songs-and-arrangements.html)
- API equivalents: `Song.hidden` boolean; `Arrangement.archived_at` plus actions `archive` / `unarchive` (unarchive must use `unscoped_arrangements`). — [API: arrangement](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/arrangement)

**Usage history ("Schedules") and reports**
- Arrangement page bottom shows "scheduled plan dates"; mobile arrangement has a "Schedule" tab ("view plan dates"). — [Add or edit an arrangement (139430)](https://help.planningcenter.com/en/139430-add-or-edit-an-arrangement.html)
- Song reports: "Songs" → report icon (top right) → choose report type → optionally choose service type(s) (for Song & File Usage, Song Schedule, CCLI Copy Activity) → date range → "Generate Report" → print from browser or CSV download button. Types: **"Song & File Usage"** (number of plans a song is used in, people who downloaded each song, people who downloaded each file format); **"Song schedule"** (songs scheduled over a timeframe); **"Rehearsal license"** (for CCLI's Rehearsal License; per arrangement shows "Downloads" and "Potential Listeners (Streams)" = unique people with access); **"File downloads"** (total downloads and number of people per file); **"CCLI copy activity"** (plans count + totals per category Print / Digital / Record / Translation from the CCLI Reporting fields on song items). Requires editor permission on Songs. — [Create song reports (139390)](https://help.planningcenter.com/en/139390-create-song-reports.html)
- CCLI reporting: "Songs" → "Actions" → "CCLI Settings" → "Link CCLI account" + checkbox "Enable Auto Reporting" → "Submit". Auto-report sends the prior week each Monday (may appear Tuesday); covers Streaming and Copyright licenses, not Rehearsal License or Streaming Plus; songs without a CCLI number are excluded; a song counts once per week across campuses/service types. Manual recording: in a plan, select song → "Song" tab of Edit Song panel → "CCLI Reporting" section → enter occurrences for Print, Digital, Recording, Translation. Report: report icon → "CCLI Copy Activity" → "Service Types" dropdown → dates → "Generate Report"; CCLI data retained two years. Only song administrators can enable; song editors can view settings/record usage/run reports. — [CCLI reporting (139389)](https://help.planningcenter.com/en/139389-ccli-reporting.html)

### Inferences
- The Songs list columns are user-selectable (column button) and the filter History tab exposes "last scheduled"; combined with `last_scheduled_at`/`last_scheduled_short_dates` on the API, a "Last scheduled" column is almost certainly one of the choosable columns, but the help center does not enumerate the column list.
- "Themes" is a free-text keyword field (string in API, "Themes: keywords you can filter by" on media), not a controlled vocabulary.
- "Song Information" popup = the editing box that holds the rarely-used fields (author, copyright, CCLI#, admin, themes, notes) per the 2016 redesign description + API assignable fields.

### Gaps
- No help article or changelog describes a "merge duplicate songs" tool; multiple searches returned nothing (the 2018 "Duplicate Detector" blog is about People). Treat merging as not supported/undocumented.
- The exact list of choosable columns on the Songs page (e.g. "Last Scheduled", "Times Scheduled") is not documented in the fetched articles.
- The exact field labels inside the "Song Information" popup were not found verbatim (only the API attribute names: title, author, copyright, ccli_number, admin, themes, notes).
- No "Contributors" concept exists on songs; the API `Contributor` vertex is a plan-level record (person who contributed to a plan), not a song author/composer field.
- No CSV import of songs is documented.

## KQ2. Arrangements & Keys — arrangement fields, sequences/sections, keys (start/end/minor/alternate-capo), popular recordings, files per arrangement vs per key, audio transposition, attachment types/file tags, MP3 download/stream, licenses, storage

### Takeaway
An Arrangement = a named version of a song carrying Length, BPM, Meter, Sequence (section labels), notes, tags, the Lyrics & Chords source text + its formatting settings, and Files; each Arrangement has Keys (Start/End key, optional minor, "Description", "Capos" = alternate keys) and files attach either to the arrangement (all keys) or to one key. Audio (MP3/M4A/AAC) can be machine-transposed to new keys; files carry "Audio Access" (download vs stream), file tags (visibility), and license counts.

### Cited Findings

**Arrangement data model (API `Arrangement`)**
- Description: "Each arrangement belongs to a song and is a different version of that song." Attributes: `archived_at`, `bpm` (float), `chord_chart` (string — lyrics and chords in standard or ChordPro format), `chord_chart_chord_color` (integer), `chord_chart_columns` (integer), `chord_chart_font` (string), `chord_chart_font_size` (allowed: 10, 11, 12, 13, 14, 15, 16, 18, 20, 22, 24, 26, 28, 32, 36, 42, 48), `chord_chart_key` (string), `has_chord_chart`, `has_chords`, `length` (integer, seconds), `lyrics` (string), `lyrics_enabled` (bool), `meter` (allowed: 2/2, 2/4, 3/2, 3/4, 4/2, 4/4, 5/4, 6/4, 3/8, 6/8, 7/4, 7/8, 9/8, 12/4, 12/8), `name`, `notes`, `number_chart_enabled`, `numeral_chart_enabled`, `print_margin` (0.0in, 0.25in, 0.5in, 0.75in, 1.0in), `print_orientation` (Portrait, Landscape), `print_page_size` (Widescreen (16x9), Fullscreen (4x3), A4, Letter, Legal, 11x17), `sequence` (array of strings "giving a label and number for each section"), `sequence_full` (array), `sequence_short` (array). Relationships: `song`, `created_by`, `updated_by`. Actions: `archive`, `assign_tags`, `unarchive`. Includes: `keys`, `sections`. Edges: `attachments`, `keys`, `sections`, `tags`; inbound from Item (`/items/{id}/arrangement`), Song. — [API: arrangement](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/arrangement)
- `ArrangementSections` — "Sections of an Arrangement, derived from its chord chart": attribute `sections` = array of `{label, lyrics, breaks_at}` (label e.g. "Verse"; lyrics = the section's lyric lines). Read-only. — [API: arrangement_sections](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/arrangement_sections)

## KQ3. Chord charts — the "Lyrics & Chords" editor, ChordPro vs standard format, special codes, formatting/print options, number & numeral charts, lyric-only PDFs, transposition of charts (song page, plan, Music Stand), importing editable charts

### Takeaway
The "Lyrics & Chords" editor stores one plain-text source per arrangement (ChordPro brackets or chords-on-own-line), renders PDFs automatically into every key/capo key of the arrangement plus optional "Numbers", "Numerals" and "Lyrics" PDFs, with per-arrangement formatting (font, size, columns, chord colour, page size, margins, orientation) and org-level "Defaults". Special all-caps codes handle section headings, key changes (TRANSPOSE KEY / REDEFINE KEY), notes ({ } / {{ }}), COLUMN_BREAK / PAGE_BREAK and HTML-like bold/italic/underline tags. Transposition on the fly is possible from a plan (music-note icon) and in Music Stand (circled key icon), only for editor-made charts.

### Cited Findings

**Editor UI (web)**
- Open: song → arrangement → "Lyrics & Chords" button in the Files section. Left pane: enter/paste lyrics and chords; "Original Key" dropdown (the key you're entering chords in); "Options" dropdown (inserts page breaks, column breaks, key changes, chord symbols, bold/italic codes); "More Codes" link; "Revert All Changes". Right pane: "Preview Key" (original key, a transposed key, or the Number/Numerals/Lyric format); "Auto-refresh" toggle; "Sequence" button (top right) edits the sequence shown at the top of the chart; "Format" button ("Aa") for print and formatting options — "Organization admins can set defaults on the 'Defaults' tab"; Download icon (PDF). Toggles "Numerals", "Numbers", "Lyrics" generate those PDFs. "Back" returns to the arrangement. Two input formats: ChordPro® (chords in brackets in the lyric line — stay aligned after transposing/font changes) and Standard chord format (chords on their own line above lyrics — may drift). Edits affect only Lyrics & Chords files, not uploaded files "unless you imported editable charts". — [Use the Lyrics & Chords editor (139440)](https://help.planningcenter.com/en/139440-use-the-lyrics---chords-editor.html)
- Mobile (Services app): "Files" tab → "Lyrics & Chords"; toolbar above the keyboard: brackets for ChordPro chords, page and column breaks, key changes, bold/italic/underline, common chord symbols; gear icon → Formatting menu: "Original Key", "Create PDFs" toggles (lyrics-only, number, numeral), "Text" and "Layout" sections (tap "X" to apply); eye icon previews the PDF; "Save" (iOS) / save icon (Android). — [Use the Lyrics & Chords editor (139440)](https://help.planningcenter.com/en/139440-use-the-lyrics---chords-editor.html)
- Outputs: "Saving generates transposed charts for every key in the arrangement"; files named "Chord Chart in [key]" appear in each key section; Number, numeral and lyrics-only PDFs appear in the Arrangement section. Number charts replace chords with scale-degree numbers (one chart works in any key); numeral charts use Roman numerals (uppercase major, lowercase minor); out-of-key notes shown with flats (b6, bVI); chord suffixes as superscripts; "These are output-only. You can't enter chords as numbers or numerals." Remove all files: delete all text → "Back"; remove capo charts only: hover key → ✏️ → "X" next to capo keys in the Capos section → "Save". — [Use the Lyrics & Chords editor (139440)](https://help.planningcenter.com/en/139440-use-the-lyrics---chords-editor.html)
- Import editable charts: requires SongSelect ("ChordPro® (Editable)") or PraiseCharts ("Chord Chart + Lyrics & Chords"); "Imported lyrics and chords populate the editor automatically when it opens." — [Use the Lyrics & Chords editor (139440)](https://help.planningcenter.com/en/139440-use-the-lyrics---chords-editor.html)
- Format settings stored per arrangement (API): `chord_chart_font`, `chord_chart_font_size` (10–48 list), `chord_chart_columns`, `chord_chart_chord_color`, `chord_chart_key`, `print_margin`, `print_orientation`, `print_page_size` (incl. screen sizes "Widescreen (16x9)", "Fullscreen (4x3)"), `lyrics_enabled`, `number_chart_enabled`, `numeral_chart_enabled`. — [API: arrangement](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/arrangement)

**Special codes (syntax)**
- `SECTION HEADING`: section headings "like CHORUS 1 or INSTRUMENTAL, in all caps". `[ Chord ]`: ChordPro; "transposed and placed on the line above the corresponding lyrics"; "Anything in square brackets will only appear in Chord Chart PDFs"; a bracketed chord on a heading line still moves up, so avoid brackets in headers. Key changes: `TRANSPOSE KEY +1` (or −n half-steps; keep typing chords in the original key) vs `REDEFINE KEY +1` (chords already typed in the new key; "does not transpose chords for chord charts, but for Number and Numeral charts, it remaps the numbers to the new key"). Key scale used: Ab, A, Bb, B, C, Db, D, Eb, E, F, F#, G. Notes: `{ note }` appears in Chord Chart and Lyric PDFs; `{{ note }}` appears only in Chord Chart PDFs. Layout: `COLUMN_BREAK`, `PAGE_BREAK`, `{{ PAGE_BREAK }}` (chord charts only). Style: `<b>`/`<strong>` bold, `<i>`/`<em>` italic, `<u>` underline, `<t>` no extra formatting. Chord symbols from the options menu: ∆ (major), ♭ (flat), ° (diminished), ø (half-diminished). — [Special codes for lyrics and chords (139441)](https://help.planningcenter.com/en/139441-special-codes-for-lyrics-and-chords.html)
- Apr 16 2024 "More Chord Chart Symbols": diminished, half diminished, major, flat; examples "C∆9#11", "G♭°7"; aimed at jazz/gospel charts. — [Changelog Apr 16 2024](https://www.planningcenter.com/changelog/services/24883991953691-improved-more-chord-chart-symbols)
- ChordPro rationale: "Place your chords inside of brackets in your lyric lines" so they anchor to syllables; "Any square brackets [ ] will be treated as special chord characters"; ChordPro and regular lines can coexist — "you don't have to redo the entire chart, you can just fix the chords or parts where there's a big shift". — [Prevent charts from shifting using ChordPro® (139439)](https://help.planningcenter.com/en/139439-prevent-charts-from-shifting-using-chordpro-.html)

**Transposing charts**
- Editor charts transpose automatically when you "add a key (or capo key)"; a version exists for every key on the song; named "Chord Chart in [Key]". On a plan: Order tab → song item → "Files" tab → hover a file → music note icon (right of the ✏️) → choose a key, or "Numbers"/"Numerals" to download that chart type. "If the music note icon is missing, the chart was not made in the Lyrics & Chords editor and cannot be transposed." - Music Stand editor: "Edit Lyrics & Chords" from the file name (plan) or from the song library (song editor permission); same toolbar/Formatting menu as mobile; "Charts transpose automatically when you add a key"; "edits update charts in all keys". Music Stand 4.7.1 (Dec 22 2025) added "side-by-side PDF preview on iPad landscape"; 4.7.3 fixed a "minor-key bug in the Lyrics and Chord Editor". — [Open the Lyrics & Chords editor in Music Stand (138518)](https://help.planningcenter.com/en/138518-open-the-lyrics---chords-editor-in-music-stand.html), [App Store: Music Stand](https://apps.apple.com/us/app/planning-center-music-stand/id368561278)

**Imported chart variants (2025)**
- Aug 26 2025: SongSelect import option "ChordPro (Editable)" opens in the "Lyric and Chord Editor" to "Edit and transpose chords, Customize formatting, Add notes for their team, Edit the song sequence"; options compared: "Lyrics" (no chords), "ChordPro (Editable)", "Chord Chart" (uneditable PDF). - Sections derived from chord chart exposed via API `ArrangementSections` (`label`, `lyrics`, `breaks_at`). — [API: arrangement_sections](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/arrangement_sections)

### Inferences
- The "Format" ("Aa") popup's controls map 1:1 to the API fields: font family, font size list, columns, chord colour, page size, margins, orientation; the "Defaults" tab sets organization defaults for new arrangements.
- A "Do-Re-Mi" (solfège) chart type exists only for SongSelect PDF imports, not for editor output (editor outputs are Numbers/Numerals/Lyrics).
- No chord-diagram rendering or AI chord detection exists; all chord data is typed/imported text.

### Gaps
- Exact labels/choices inside the "Format" popup (font list, column count range, colour picker) are not described in the help center; only the API enumerations are known.
- Enharmonic (flat vs sharp) spelling preference for transposed charts is not documented beyond the 12-key scale list (Ab, A, Bb, B, C, Db, D, Eb, E, F, F#, G).
- No documentation of chord diagrams, autoscroll, or a "capo" display toggle inside the editor itself.

### Inferences
- "Layouts" in the user's question map to two different things: (a) Music Stand's shared "Reorder Pages"/"rearrange pages" (persisted as `Attachment.page_order`) and scroll/two-page view modes; (b) the API's `Layout`/`selected_layout` on plan items, which corresponds to Services' *stage layouts* (stage diagrams saved as plan files), not a Music Stand resource. There is no `Layout` vertex in the 2018-11-01 Services API docs.
- Annotations are not exposed in the public API (no vertex); they are stored server-side per user/PDF (Web Music Stand lets you pick an "annotation set").
- Music Stand has no autoscroll and no in-app capo toggle beyond selecting a capo key chart; transposition is view-only.

- The Settings article does not enumerate the exact PDF-section toggle labels (scroll direction values, "Vertical Full Page"/"Vertical Half Page" names come from the 2018 blog).
- No community (Reddit/forum) threads were retrievable to describe real-world usage pain points.

## KQ9. API data model summary (Services v2, 2018-11-01) for the song/media/rehearsal domain

### Takeaway
The relevant vertices are Song → Arrangement → Key, with Attachment attachable to Song/Arrangement/Key/Media/Item/Plan/ServiceType, AttachmentType(+Group) for file tags, Tag/TagGroup, SongSchedule & MediaSchedule for usage, ArrangementSections (derived), Zoom (per-user view state), SongbookStatus (async PDF), and Item linking song/arrangement/key/media with a per-plan custom sequence.

### Cited Findings
- Vertex list includes: Arrangement, ArrangementSections, Attachment, AttachmentActivity ("Returned from the `open` attachment action."), AttachmentType, AttachmentTypeGroup, Contributor, CustomSlide ("used for adding text intended for display on a screen"), Item, ItemNote, Key, Media, MediaSchedule, SkippedAttachment, Song, SongSchedule, SongbookStatus, Tag, TagGroup, Zoom (no `Layout` vertex documented). — [API index](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01)
- Song attributes/edges — see KQ1; Arrangement/Key/Attachment/AttachmentType/Zoom — see KQ2; Media/MediaSchedule — see KQ5; Item — see KQ2; SongbookStatus — see KQ6. — [API: song](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/song), [arrangement](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/arrangement), [key](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/key), [attachment](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/attachment), [media](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/media), [item](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/item)
- `Contributor` ("A Contributor Resource"): `contributable_action`, `contributable_category`, `contributable_type`, `full_name`, `photo_thumbnail_url`; relationships `plan`, `person` — a plan-level change-contributor record, unrelated to song authorship. — [API: contributor](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/contributor)
- `Plan` actions: `autoschedule`, `import`, `item_reorder`; no songbook action on Plan. — [API: plan](https://api.planningcenteronline.com/services/v2/documentation/2018-11-01/vertices/plan)

### Inferences
- Songbook creation is triggered from the web UI (not a documented public API action) and polled via `SongbookStatus`.

### Gaps
- `Layout` is referenced as the type of `Item.selected_layout` but has no documented vertex; its attributes are unknown.
- Annotations, Music Stand sessions, page-turn settings and skipped-file lists have no documented public API attributes (only `SkippedAttachment` appears by name).
