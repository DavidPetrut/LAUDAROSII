# Planning Center Services — Help Center, API and Changelog completeness catalog (as of 2026-10-12)

Scope note: this is the "safety net" catalog. It enumerates (A) every section and article of the official Services help center with a one-to-two-line gist, (B) every Services API resource ("vertex") with attributes, enumerations and the user-facing feature it backs, plus webhooks, and (C) every Services-tagged changelog entry from January 2024 through October 2026 with a gist, plus cross-product entries that affect Services users. Official labels are kept in quotes; deprecated/renamed items are flagged.

## Key Question 1 — Help center: all categories, sections and article titles (with gists)

### Takeaway
The official Services documentation now lives in the unified "Planning Center Help" site at help.planningcenter.com (a Paligo-generated static site launched as a changelog item on Apr 15, 2026); the Services category contains 14 sections and 168 leaf articles, and Services-relevant material also sits in a separate "Music Stand" category (4 sections, 25 articles) and in global categories ("Set up Services", "Permissions in Services", "Toolbar"/Chat, "Integrations", "Billing and subscriptions", "Church Center"). The legacy hosts (support.planningcenter.com → support.planningcenteronline.com, and pcoservices.zendesk.com) now return HTTP 403 and could not be enumerated.

### Inferences
- The help center has no sections literally named "Notifications/Emails/Texts", "Matrix", "Settings", "Permissions", "Billing" or "Troubleshooting" inside Services; those topics are covered by articles inside the sections above ("Set up the matrix", "Manage service type settings", "Manage default permission settings", "Troubleshoot common email problems", "Set up and respond to text notifications") and by global categories ("Roles and permissions" → "Permissions in Services"; "Billing and subscriptions"; "Security"; "Account settings"). A writer should therefore not expect a Services-specific billing or settings chapter in the docs.
- "Projector" (the retired presentation app) has zero hits in the current help-center search index, consistent with its 2018–2019 retirement (see Key Question 3); the API still carries a vestigial `Organization.projector_enabled` attribute and `Item.selected_layout`/`selected_background` fields.
- The numeric article IDs are contiguous within sections (e.g., 139383–139473 for "Plan your service"), which suggests the current site was migrated as a block from the legacy Zendesk centers; titles are modern ("Automations in Services", "Merge duplicate teams" id 181298 is a newer addition).

### Gaps
- The legacy Zendesk-hosted help centers (pcoservices.zendesk.com; support.planningcenteronline.com) return 403, so I could not compare the legacy article list with the current one or capture legacy-only articles.
- Gists are the opening ~200 characters of each article (from the site's own search index), not full summaries; articles that start with a video callout have short gists.
- The help center does not enumerate feature availability per pricing tier; pricing is covered elsewhere ("Planning Center pricing" page) and by another researcher.

## Key Question 2 — API: all Services resource types, attributes, enumerations, feature mapping, webhooks

### Takeaway
The current Services API (version "2018-11-01", OpenAPI 3.1.1 document reporting `x-pco-api-version` 16.4.0) documents 65 vertex types — the assignment's candidate list is confirmed except that "Layout" is not a documented vertex, and 11 extra vertices exist (AttachmentTypeGroup, Attendance, Email, EmailTemplateRenderedResponse, FolderPath, ItemAssignment, PlanImportMetadata, ServiceTypePath, SignupSheetMetadata, SkippedAttachment, SplitTeamRehearsalAssignment); the older "2018-08-01" version was retired on Apr 2, 2024. Webhook event names are only discoverable through the authenticated `/webhooks/v2/available_events` endpoint; no official public list exists.

### Inferences
- The API vocabulary preserves older product terminology that the UI has since renamed: "Ministries" = Service Types, "People Categories" = Teams, "Custom Properties & Fields" = Tags & Tag Groups (confirmed by the May 19, 2025 custom-reports changelog), and `team_members` is the endpoint name for PlanPerson records. A writer should treat these as synonyms.
- Several API attributes reveal settings that exist in the product but are easy to miss in docs: per-team `gap_alert_days`, `direct_messages_enabled`, `default_prepare_notifications`, `viewers_see`, `stage_color`; per-service-type `scheduled_publish`, `background_check_permissions`, `attachment_types_enabled`; per-organization CCLI auto-reporting and extra file storage charges; per-person `preferred_max_plans_per_day/month`, `preferred_app`, `ical_code`.
- Webhook events for Services resources beyond LIVE very likely exist (the available_events endpoint is generic), but their names could not be verified without an authenticated account.

### Gaps
- No public, official list of Services webhook event names (`/webhooks/v2/available_events` requires authentication); only `services.v2.events.plan.live.updated` is attested, and only by a third-party project.
- The OpenAPI document does not give per-attribute descriptions for many fields (e.g., `Team.viewers_see`, `Team.stage_variant`, `Person.status`, `Schedule.reschedule_declines`, `PlanPersonTime.status`), so their exact value sets are unknown.
- The 2018-08-01 vertex list was not captured (retired); per-vertex "permissions" notes are not present in the docs pages.

### Inferences
- The 2024–2026 Services roadmap clusters into: (1) Chat (2024–2026, culminating in DMs and moderation), (2) scheduling flexibility (positions-per-time, gap alerts, multi-service-type teams, new preferences, volunteer replacements, household scheduling), (3) song-content imports (SongSelect ChordPro/2-column/number charts, PraiseCharts selection, version linking), (4) leaders-on-items and reporting (custom reports, people reports), (5) mobile platform work (v6 tabs, sequence editing, media player tabs, CarPlay, Liquid Glass, login settings).
- Entry "types" used by the changelog are "New", "Improved", "Update"/"Updated", "Changed", "Fixed", "Upcoming" and "New & Improved"; only Services-tagged rows are listed above, but Chat entries are often dual-tagged (services + groups/church-center).

### Gaps
- Changelog entry bodies were captured up to ~1,300 characters each; a few long entries (e.g., "Planning Center Chat", "Public Plan Upgrades", "Teams can belong to multiple Service Types", "Volunteer replacements") have further details beyond what is summarized.
- Blog posts (planningcenter.com/blog) and YouTube video titles were not enumerated for 2024–2026; the changelog was treated as the authoritative release list.
- No Services-tagged entries exist for Jan 2024 or Oct 1–12, 2026 on the index pages; if entries are back-dated later they would be missed.
