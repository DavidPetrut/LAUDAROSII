# Planning Center Services — UI Visual Tour (screen-by-screen notes from images)

Method note: All descriptions below were written after LOOKING at the actual images in the built-in browser pane (marketing screenshots on planningcenter.com, help-center article screenshots, app-store listing screenshots). Every UI label is quoted exactly as seen. Where I infer a behaviour that is not literally visible, it is marked "(inference)". Marketing images are partly stylised (grey placeholder bars instead of real text in some areas) — this is noted where relevant. Product state: 2025–2026 (the marketing images use dates from 2022–2024; the "phoenix" file names indicate the current redesigned UI).

Global design language (seen consistently across all screenshots):
- Primary brand colour of Services is green (olive/leaf green, approx. #6B8E3A–#7FA03C for buttons, #3F8F3F-ish for links/titles). The Services product badge is a green rounded square icon with three white horizontal list lines, followed by the word "services" in lowercase.
- Top app bar is white/light with a green-to-blue gradient in the marketing versions; it contains, left to right: the product switcher ("services" + chevron "v"), the main nav tabs, and on the right a search icon, an organisation chip (e.g. "Carlsbad Church" with a chevron) and a round avatar.
- A thin vertical rail of icon buttons sits on the far right edge of app pages (help "?", notifications bell, a document/clipboard icon, a share/export icon).
- Primary action buttons are solid olive-green with white text ("Save 1 Blockout", "Submit", "Send", "Transpose", "Select this position", "Sign up Maile"); secondary/cancel actions are plain text ("Cancel", "Back").
- Modal dialogs have a pale green-to-blue gradient header bar with the dialog title in dark text ("Add Arrangement", "Transpose Audio", "Top Songs", "Add a file").
- Song keys are displayed as small round green badges with white letters ("Bb", "E", "D", "B", "G", "F", "A") next to song titles in orders of service.
- Section headers inside lists are grey bands with upper-case letter-spaced text ("START OF SERVICE", "PRAISE AND WORSHIP", "WELCOME AND ANNOUNCEMENTS").

## Key Question 1 — What does each main (web) screen look like and what controls does it expose?

### Takeaway
The web app is organised around a top navigation ("My Schedule", "Plans", "Songs", "Media", "People"), with the Plan page (tabs "Order", "Teams"/"People", "Times", "Notes", "Files", "Rehearse") and the Matrix (service-type × date grid) as the core working surfaces; dialogs for blockouts, signup sheets, arrangements, transposition and file import are the main secondary surfaces visible in the official imagery.

### Inferences
- The web app uses a consistent two-level structure: top nav for modules ("My Schedule" / "Plans" / "Songs" / "Media" / "People"), and within a plan a tab strip ("Order" / "Teams" / "Rehearse" on web; "Order" / "Teams" / "Times" / "Notes" / "Files" on mobile), with Times/Files/Notes living in a left sidebar on web.
- Status iconography is consistent everywhere: green ✓ = confirmed, red ✕ = declined, yellow/amber "?" or clock = unconfirmed/pending; red numeric circle = "Needed" count; day chips are colour-coded (green "Su"/"SUN", pink "FRI").
- Key badges: blue circles in the current web UI, green circles in mobile and older marketing art.
- Primary buttons: blue in the current web UI ("Add a song", "Default/Expanded" toggles, toggles), olive-green in the marketing/mobile art.

### Gaps
- Marketing images are stylised: real sidebars/filters on "My Schedule" are placeholder bars; I could not see exact labels there from marketing imagery.
- I did not find a help-center screenshot of the full "People" page list or the "Teams" index page; descriptions of those come from text only (see KQ2).
- Planning Center "Projector" was discontinued (Feb 2018 blog post "The End of Planning Center Projector"; support ended Feb 11, 2019; WorshipStorm Projector is the suggested replacement) — there is no current Projector screen to describe. https://www.planningcenter.com/blog/2018/02/the-end-of-projector
