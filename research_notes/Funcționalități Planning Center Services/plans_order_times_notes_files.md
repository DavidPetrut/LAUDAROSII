# Planning Center Services — Service Types, Plans, Order of Service, Times, Notes, Files, Templates, Series, Dashboard, Printing (2025–2026)

Scope note: Notes cover only the Services product. Teams/scheduling, Songs/arrangements, Music Stand, LIVE and the mobile apps are mentioned only where plans depend on them. All UI labels are quoted exactly as Planning Center writes them. The official help center moved from `pcoservices.zendesk.com` / `support.planningcenter.com` to `help.planningcenter.com/en/<id>-<slug>.html` (the numbered URLs are the canonical ones; the un-numbered variants exist but returned 404 to automated fetches). The API documentation at `developer.planning.center/docs/#/apps/services/2018-11-01/vertices/<vertex>` is a JavaScript app that renders from `api.planningcenteronline.com/docs/apps/services/versions/2018-11-01/vertices/<vertex>`; the API version in force is `2018-11-01` (support for `2018-08-01` ended Feb 29, 2024 — [Changelog 2024](https://www.planningcenter.com/changelog/2024)).

## 1. Organization structure: Folders, Service Types and Service Type settings

### Takeaway
Services is organized as Folders (nestable, optionally tied to a Campus) → Service Types (the container for plans, teams and templates; has a frequency, time preferences, note categories, files, item row colors, LIVE permissions, Public View settings, Limited File Visibility) → Plans. Only administrators can add service types and folders; most service-type settings are admin-only.

### Cited Findings

**Hierarchy and Plans page**
- "An individual plan page contains the service order, scheduled people, and times pertaining to a service. A service type contains plans, teams, and templates related to a particular kind of service." A folder "can contain multiple service types or folders. You can create as many folders as you want to organize your Plans page and add another level for managing permissions." Suggested folder names: locations or departments. Selecting "Plans" in the top navigation opens your most recently viewed folder; administrators can set a person's default folder — [Main plans page overview](https://help.planningcenter.com/en/139397-main-plans-page-overview.html)
- Services on the same campus get a service type each ("Adult, Youth, or Preschool") — [Set up the service order](https://help.planningcenter.com/en/139467-set-up-the-service-order.html)
- API: "A folder is a container used to organize multiple Service Types or other Folders." Folder attributes: `container` (string), `created_at`, `name`, `updated_at`; relationships `ancestors` (Folder), `parent` (Folder), `campus` (Campus). Assignable on create/update: `name`, `parent_id`, `campus_id`. Endpoints `GET/POST /services/v2/folders`, `/folders/{id}`, `/folders/{folder_id}/folders`, `/folders/{folder_id}/service_types`; can include `service_types`; order by `name`; query `where[parent_id]` — [API Folder](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/folder)

**Folders (create / edit / delete)**
- Folders "group service types by campus, ministry, or any other structure your church uses. Only people and plan administrators can add or edit folders." — [Create, edit, or delete folders](https://help.planningcenter.com/en/142850-create,-edit,-or-delete-folders.html)
- Create: "Plans" page → "Actions" (top right) → "Add Folder" → popup fields "Folder Name" and "Campus" (default "None"; "Setting a campus also sets the correct time zone for reminder emails and calendar feed subscriptions") → "Accept." — same source
- Edit: open folder → "Actions" → "Edit Folder" → popup: rename text field; "Parent" (move folder inside another folder); "Campus"; "Reorder Service Types" (drag the handle to the left of each service type); the article also mentions updating matrix options; → "Save." — same source
- Moving a service type into a folder is done from the service type's settings ("Folder" option), not from the folder — same source + [Manage service type settings](https://help.planningcenter.com/en/142848-manage-service-type-settings.html)
- Delete: only empty folders; "If the folder contains a service type, either delete or archive it first, or move it to another folder. When the folder is empty, select 'delete this folder.'" — [Create, edit, or delete folders](https://help.planningcenter.com/en/142850-create,-edit,-or-delete-folders.html)
- Default (starting) folder per person: requires scheduler permissions or higher; search the person → profile → "Details" tab → "Current Folder" section → "Find a folder" → choose or type to search; takes effect next time they open the main plans page — [Set the current folder](https://help.planningcenter.com/en/142866-set-the-current-folder.html)
- 2019 "new Plans tab": header shows the full folder path, each segment clickable; sub-folders are stacked horizontally so Service Types sit higher on the page — [The new Plans tab (Apr 30, 2019)](https://www.planningcenter.com/blog/the-new-plans-tab)

**Creating a Service Type**
- "Plans" → "Actions" (top right) → "Add Service Type" opens a guided wizard: (1) name and frequency; (2) first date and time the service meets, with "Add another service time" for multiple times on the first plan; (3) optional teams from a "common teams" list (editable later). To schedule an existing team in another service type, add the new service type to the team's assigned service types in that team's settings. "Only administrators can add service types and folders." After creating multiple service types you can rearrange their order on the "Plans" page from their folder. "Some pricing packages cap the number of service types" (upgrade prompt if exceeded) — [Create a new service type](https://help.planningcenter.com/en/142847-create-a-new-service-type.html)
- Copy a service type: gear icon next to service type → "Settings" → "Actions" → "Copy" → name → "Copy To" folder dropdown → optional checkbox to copy the service type templates ("This converts people scheduled in the templates into needed positions") → "Submit." Copied: "All non-people settings" (people in "Permissions to Control Live" are not copied), the "Teams" tab layout and top settings (not team members, leaders, or tags on tag teams). Not copied: plans, permissions, team members, team leaders — same source
- Service type wizard note: "If you create a new service type, a wizard guides you through setup and helps you create the first plan for that service type." — [Set up the service order](https://help.planningcenter.com/en/139467-set-up-the-service-order.html)

**Service Type settings page (gear → "Settings")**
- Path: "Plans" → ⚙️ icon next to the service type → "Settings" from the dropdown. "Changes apply to all plans in the service type." — [Manage service type settings](https://help.planningcenter.com/en/142848-manage-service-type-settings.html)
- Service type name: select the name in the top left, enter new name, press Enter — same source
- "Time preferences": select the "Times" button in the top left; "Add Day" to add a time, then "Save"; trash icon to delete, pencil to edit. "These times apply to every split team in the service type. Use actual service times, not report times or rehearsals." Existing plans with split teams may need these times added manually; new plans created from a template with split teams automatically receive these times; "These times determine the service time options when adding needed positions for split teams in templates." — same source. (See also "Templates only offer times listed here"; "Split-team positions for new times can't be added until they're listed" — [Move to multiple service times](https://help.planningcenter.com/en/142916-move-to-multiple-service-times.html))
- "Options" section: **"Frequency"** — usually "Weekly," other options available; choose "None" for sporadic events; with "None," the "Copy Times From" and "Starting On" fields are grayed out when creating a plan so you add a service time manually later. **"Folder"** — choose a parent folder. **"Limited File Visibility"** — when on, team members see only files tagged for their position (dropdown values "Enabled"; a "Configure" button then opens a setup wizard) — [Manage service type settings](https://help.planningcenter.com/en/142848-manage-service-type-settings.html); [Set up limited file visibility](https://help.planningcenter.com/en/139416-set-up-limited-file-visibility.html)
- "Item row colors" section: "Add," choose a color, "Save"; pencil to edit. "Colors must be enabled within a plan before they appear." — [Manage service type settings](https://help.planningcenter.com/en/142848-manage-service-type-settings.html)
- "Files" section: "Add" to upload or link files; "They appear in the Files section of every plan in the service type." — same source
- "Notes" section: **Item note categories** — "Add" to create; pencil to edit/delete; drag with six-dot icon to reorder; "Move rarely used categories to the 'Occasionally Used' section to hide them when empty." **Plan note categories** — "Add," pencil to edit/delete, six-dot reorder — same source
- "Permissions" section: "Controls who can control Services LIVE. By default, only editors and administrators can. Select 'Add' to grant control to others." — same source
- "Public view" section: "General" (item details to include), "Item Types" (plan item types to include), "Links" (media platforms to link for songs and media; "These apply only to links on the scheduled arrangement. Item and plan attachments are not published in Church Center."), "Schedule Publish" (toggle to automatically publish plans in Church Center on the day of the first service time) — same source
- Older blog (2018, UI labels may differ): "other than Files, the settings on this tab can only be changed by Administrators of this Service Type. Editors and Schedulers can still view the settings," with tooltip on restricted settings; "Sticky" category option was renamed "Frequently Used" — [Service types and reports (2018)](https://www.planningcenter.com/blog/2018/03/service-types-and-reports)
- Older blog (2011): item note categories could be edited from the gear over the "Item Notes" heading while editing an item; categories draggable to reorder; "Sticky Categories will always show up when you are editing items, and non-sticky categories will stay out of your way until you click the new 'add another note' button"; deleted categories (and plans) recoverable up to 7 days via "Recently Deleted" — [Service setup category changes (2011)](https://www.planningcenter.com/blog/2011/04/service-setup-category-changes-item-information) (dated; current recovery window for files/teams/service types is 30 days, see §11)
- API ServiceType attributes: `archived_at`, `attachment_types_enabled` (bool), `background_check_permissions` (string), `comment_permissions` (DEPRECATED), `created_at`, `custom_item_types` (array of `{name, color}` mapping an item-title substring to a color; valid colors `#e8f6df, #e0f7ff, #e6e2fd, #ffe0e8, #ffedd1, #cfcfcf, #eaebeb, #ffffff`), `deleted_at`, `frequency` (string), `last_plan_from` (string), `name`, `permissions` (string), `scheduled_publish` (bool), `sequence` (integer), `standard_item_types` (array of `{name, color}` where valid names are `Header`, `Song`, `Media`), `updated_at`; relationship `parent` (Folder). Assignable: `attachment_types_enabled, background_check_permissions, custom_item_types, frequency, last_plan_from, name, parent_id, scheduled_publish, sequence, standard_item_types`. Associations: `attachments`, `item_note_categories`, `live_controllers`, `plan_note_categories`, `plan_person_times`, `plan_templates`, `plan_times` (filters `future, named, not_deleted, past`), `plans` (filters `after, before, future, no_dates, past`), `public_view`, `team_positions`, `teams`, `time_preference_options`, `unscoped_plans` (filter `deleted`). Order by `name`, `sequence`; query `where[id]`, `where[name]`, `where[parent_id]`; organization-level filter `no_parent` — [API ServiceType](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/service_type)
- API `create_plans` action on a service type (`POST /service_types/{id}/create_plans`): attributes `count` (max 12, default 1), `copy_items`, `copy_people`, `team_ids`, `copy_notes`, `as_template` (create the new plans as templates), `base_date` (ISO 8601 date to start building plans); relationships `plan` (copy times, items, people, notes from) and `template` (collection of templates to copy items, people, notes — "not times" — "Order dependant. Takes precedence over plan.") — same source
- API TimePreferenceOption ("A Service Time a person prefers to be scheduled to"): `created_at`, `day_of_week` (int), `description`, `minute_of_day` ("0 for 12:00 am, 1 for 12:01 am, 100 for 1:00 am, through 2359 for 11:59pm"), `sort_index`, `starts_at`, `time_type`, `updated_at`; order by `day_of_week`, `hour_of_day` — [API TimePreferenceOption](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/time_preference_option)
- API ItemNoteCategory ("A category of plan item notes for an entire Service Type"): `created_at`, `deleted_at`, `frequently_used` (bool), `name`, `sequence`, `updated_at`; relationship `service_type`; read-only endpoints (`GET /service_types/{id}/item_note_categories[/{id}]`) — [API ItemNoteCategory](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/item_note_category)
- API PlanNoteCategory ("A category of plan notes for an entire Service Type"): `created_at`, `deleted_at`, `name`, `sequence`, `updated_at`; relationships `service_type`, `teams` (Team); read-only — [API PlanNoteCategory](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/plan_note_category)
- API PublicView ("Manage options for a public plan"): booleans `amazon, headers, item_descriptions, item_lengths, itunes, media_items, regular_items, series_and_plan_titles, series_artwork, service_times, song_items, spotify, vimeo, youtube`; `GET /service_types/{id}/public_view` — [API PublicView](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/public_view)

**Archiving / deleting / restoring service types**
- Archive: gear → "Settings" → "Actions" → "Archive" → "Yes, archive". Teams in an archived service type are archived too and disappear everywhere. Restore: "Plans" page → "view archived service types" at the bottom of the list (shows archive date and who archived) → restore button → "Yes, restore!" Restoring brings back teams active at archive time; people with specific permissions in that service type are reset to "Same as Parent." — [Archive, delete, and restore service types](https://help.planningcenter.com/en/142849-archive,-delete,-and-restore-service-types.html)
- Delete: gear → "Settings" → "Actions" → "Delete" → "Yes, delete forever". Moves to a "recently deleted" section; "view recently deleted service types" at the bottom of the list; recoverable by an administrator within 30 days ("Yes, restore!"); after that the service type, its plans and teams are permanently removed — same source; the 30-day window (previously 7 days for teams and service types) was announced May 19, 2025 — [Changelog: A time machine for deleted files, teams, and service types](https://www.planningcenter.com/changelog/services/37152089395611-new-a-time-machine-for-deleted-files-teams-and-service-types)

**Teams vs service types (2026 change)**
- Feb 4, 2026: "Teams can belong to multiple Service Types (and even none at all)". Teams can be created from the Teams page; a "Service Types" section in create/copy lets you select multiple; assignable from Team Settings; you can only add a service type you have permission to manage; Service Type badges appear in Team settings and people views; "Last Scheduled" now considers all service types; merging works across service types; a team can exist before being tied to any service type — [Changelog Feb 4, 2026](https://www.planningcenter.com/changelog/services/new-teams-can-belong-to-multiple-service-types-and-even-none-at-all-)

**Permissions relevant to service types / plans**
- Levels (lowest→highest): "Scheduled viewer" (sees "My Schedule" and plans they're scheduled for after a scheduling email is sent), "Viewer" (all plans), "Scheduler" (teams they lead; can add rehearsal and other times but not service times), "Editor" (add/edit all plans and people; delete people or plans they created), "Administrator" (everything incl. "Manage service type settings," reschedule plans, copy service types, recover deleted/restore archived service types, edit custom reports), "Organization administrator" — [Permissions in Services](https://help.planningcenter.com/en/136863-permissions-in-services.html)
- Per-service-type action table: Add a plan — Editor/Admin; Delete a plan — Editor/Admin; Reschedule a plan — Scheduler+; Edit service order — Editor+; Edit service time — Editor+; Edit Rehearsal or Other time — Scheduler+; Add/edit/view plan notes — Scheduler+; Edit/import/export templates — Scheduler "People only," Editor+ full; Upload an attachment — Editor+ — same source
- Folder/service-type-specific permissions: person profile → "Actions" → "Manage permissions" → "Folders" tab in the Service Types section; "Same As Parent" inherits from the parent folder (or from the overall People and Plans level if no parent) — same source
- File access is set separately under "Manage permissions" for "Plan" files, "Song" files, "Media" files — same source

### Inferences
- `ServiceType.sequence` + the folder "Reorder Service Types" drag handle imply service types are manually ordered within a folder; `Folder.container` is undocumented but likely indicates folder type.
- "Attachment types" (API `attachment_types_enabled`) is the legacy name of the UI setting now called "Limited File Visibility" + "File tags" (see §7).
- "Item row colors" in the UI correspond to `custom_item_types` (title-substring → color) plus `standard_item_types` (per item type Header/Song/Media → color) in the API; the palette is the 8 fixed pastel hex values.

### Gaps
- The exact list of "Frequency" values (beyond "Weekly" and "None") is not listed in any fetched source; the API only types `frequency` as string.
- Whether a service type has a per-service-type time zone (vs. campus-derived) is not documented; the folder "Campus" setting is what sets the time zone for reminders/calendar feeds.
- The "Plan item default length" / "Attachment types" settings named in the research brief do not appear under those names in the current settings page; no source confirms a "default item length" setting.

## 2. Dashboard / home: "My Schedule", the "Plans" page, master calendar

### Takeaway
"My Schedule" is the landing page after login (scheduling requests, signup sheets, confirmed plans, household members, blockouts, email leaders). The "Plans" page shows the current folder with a mini calendar + "View Master Calendar," a "Matrix" button, an "Actions" button (folders, service types, calendar settings), and gray service-type bars listing upcoming plans with "Add plan" at the bottom and a "Deleted plans" button.

- "My Schedule is the first screen that you see when you log in to Services. In My Schedule, you can view all of your scheduling requests, available signup sheets, and confirmed plans." Household members' schedules can be managed via their profile icon "if you are part of a household in People and have permission to manage household members' schedules"; from the top of the page "you can add blockouts, or email any of the leaders of the teams you are assigned to." Plan details for team members show "Your assigned position," "Your times," "Notes for your assignment." ## 3. Plans: creating, copying, title/series, actions menu, deleting/recovering, rescheduling, sharing/public view, change tracking

### Takeaway
A plan is created from a service type with "Quantity," "Copy Times From," "Starting On," and per-date "Templates"; it can also be copied ("Copy plan") from another plan or template with "Include" options (Items/Notes/Teams). A plan has an optional title and series (title + artwork), a Public View toggle for Church Center, permalinks, a collaborators log, and can be rescheduled, deleted (30-day recovery) and printed. The plan page is split into a header, a collapsible sidebar (Times, Teams, Files, Notes, Sermon Episode) and "Order" / "Teams" / "Rehearse" tabs.

### Cited Findings

**Creating a plan (web)**
- Requires editor or administrator in the service type. "Plans" → folder → scroll to service type → "Add plan" at the bottom → popup fields: **"Quantity"** (number of plans), **"Copy Times From"** (a previous plan date; "The dropdown shows the previous four plans and the last four recently viewed plans"), **"Starting On"** (start date; "For multiple plans, they recur based on the service type's frequency setting"), **"Templates"** ("Template for the chosen date. If you add multiple dates, you can pick a different template for each") → "Add" (the button label also appears as "Add 1" when quantity is 1) — [Create or copy a plan](https://help.planningcenter.com/en/139399-create-or-copy-a-plan.html); [Move to multiple service times](https://help.planningcenter.com/en/142916-move-to-multiple-service-times.html)
- "Copy Times From" offers "None (no times)" — then add times manually in the plan — [Move to multiple service times](https://help.planningcenter.com/en/142916-move-to-multiple-service-times.html); with Frequency "None" both "Copy Times From" and "Starting On" are grayed out — [Manage service type settings](https://help.planningcenter.com/en/142848-manage-service-type-settings.html)
- Mobile: Plans → folder → service type → plus icon → "Template" field, "Quantity," "Starting On" ("Times are copied automatically from the most recent plan in that service type") → "Save" — [Create or copy a plan](https://help.planningcenter.com/en/139399-create-or-copy-a-plan.html)
- API: `POST /service_types/{id}/plans` assignable `title, public, series_id, series_title`; PATCH also `reminders_disabled`; multi-plan creation via the `create_plans` action (max 12) — [API Plan](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/plan); [API ServiceType](https://developer.planning.center/docs/#/apps/services/2018-11-01/vertices/service_type)

**Copying a plan ("Copy plan")**
- Web only. ## 4. Times: service, rehearsal and other times

### Takeaway
A plan has three time types — "Service" (sets the plan's date and drives conflicts), "Rehearsal," and "Other" — each with name, date, start, end, assigned teams **and positions** (since Apr 2025), per-team reminder days, and "Create this time in future plans." People only see a plan on My Schedule / get reminders if their team/position is assigned to at least one time.

### Cited Findings
- Time types: **Service times** ("The main type. They set the plan's date and drive scheduling conflicts. A plan without one is listed as 'No dates' on the Plans page"); **Rehearsal times** (appear in reminder emails); **Other times** (arrival, setup/teardown). Times appear in the Times section of the plan page, color-coded by day — [Add and assign times](https://help.planningcenter.com/en/139401-add-and-assign-times.html)
- Add a service time (web): plan → "Add" in the Times section → "Service" tab → start and end times ("The end time affects conflict accuracy") → date → Assigned Teams and Positions ("All service type teams are assigned by default"; remove a team with the minus icon; "Split teams can't be removed"; expand a team to assign/unassign specific positions; choose a reminder setting from each team's dropdown) → optional "Create this time in future plans" (only shown if future plans exist) → "Save." Mobile: Times tab → "Add" → Type "Service" → times, teams, positions, reminders → "Add Time" → toggle "Create in future plans" → green check — same source
- Add rehearsal/other (web): "Add" → "Rehearsal" or "Other" tab → name if needed → start, end, date ("should fall in the plan's week") → search/assign teams and positions (e.g., only sound techs) → "Create this time in future plans" → "Save." Popup is called "Add Time"; it lets you "search for the teams and positions that should be assigned to this time and set up optional automated reminders for each time" — same source
- Edit: users with people and plan editor permissions or higher; select the time; change type via "Service"/"Rehearsal"/"Other" tabs; options "Update this time in future plans" (affects same-name, same-type, same-time entries) and "Update existing people's assignments." - Delete: one plan at a time, no bulk delete; "Delete" → "Yes, delete forever" (mobile "Delete Time" → "Yes") — same source

- Apr 22, 2025: "Assign times to positions, not just teams!" — in the Times modal a team shows how many of its positions are assigned; bulk assign/unassign; position quick search; mobile 6.3: Times tab → choose a time → set its default positions. ## 5. Order of service: item types, item fields, start-time computation, reordering, item notes, leaders, colors, sequences, item times

### Takeaway
Four item types ("Item," "Header," "Song," "Media"), each with Name, Length (mm:ss) plus a Before/During/After-service position (optionally per service time), Description, rich-text "Detail," per-category "Notes," "Files," and "Song/Media" link (arrangement + key, custom sequence), and "Item leader"/"Song leader" (person or position). ## 6. Plan Notes

### Takeaway
Plan notes are per-plan text notes in a service-type-defined category, optionally assigned to one or more teams; they appear in the plan's "Notes" sidebar, in the mobile "Notes" tab, in Church Center, in reminder emails for assigned teams (not scheduling emails), and in plan reports; they can be "Sent" as an email and created from a sent email.

### Cited Findings
- "Plan notes share information for a whole plan or for a specific team, such as sermon notes that not everyone needs. Notes assigned to a team appear in that team's reminder emails. Plan notes are not included in scheduling emails." Each note uses one of the service type's plan note categories (admins customize them in service type settings) — [Use plan notes for team information](https://help.planningcenter.com/en/139462-use-plan-notes-for-team-information.html)
- Add (web): plan → left sidebar "Notes" (expand if grayed) → "Add" beside the header → choose a category → note text → "Add" under Assigned Teams to pick teams → "Save" or "Send" (saves and emails the team). Mobile: "Notes" tab → "Add" → "Select a Category" → "Note Text" → toggle teams → green check — same source
- View: web expand "Notes"; "Show [number] note(s) for other team(s)" for teams you don't lead; mobile "Notes" tab shows notes for your team; also viewable in Church Center — same source
- Send as email (web only): open the note → "Send..." (emails all scheduled members of assigned teams). Create a note from an email (web only): when emailing a plan group, add text above the default body → "Send [number of people]" → popup: category, text, teams → "Yes, save note." — same source
- Templates can contain plan notes ("Notes section on the left → 'Add'"); Copy/Import/Export dialogs have a "Notes" checkbox; "Reschedule - Order of Service" has an option to move plan notes — [Set up plan templates](https://help.planningcenter.com/en/139469-set-up-plan-templates.html); [Import a template or plan](https://help.planningcenter.com/en/139470-import-a-template-or-plan.html); [Reschedule your plans](https://help.planningcenter.com/en/139460-reschedule-your-plans.html)

- "Public/private" notes: visibility is governed by team assignment (notes for other teams are collapsed behind "Show [n] note(s) for other team(s)"); there is no documented per-note public flag, and plan notes are not published to the public plan.

- Editing/deleting a plan note and any character limits are not described in the fetched article.

## 7. Attachments / Files (plan, item, service type, song/media), file tags and limited visibility, storage

## 8. Plan templates (and import/export)

### Takeaway
Plan templates live per service type (gear → "Templates"), contain items/headers (with leader positions), plan notes, scheduled people and needed positions, but no dates/times; they are applied at plan creation ("Templates" dropdown), imported into existing plans ("Import template" with Items/Notes/Teams and "Import To"), or produced from a plan ("Save as template").

### Cited Findings
- "Plan templates help you work faster by saving a snapshot of commonly used plan items and notes." Contents: items/headers with details, item/song leader positions, notes, scheduled team members and needed positions (via "Teams" tab). "Templates have no dates or service times. You can't add times to them." Edit: click template name to rename (Enter); "Actions" (top right): save as another template, copy into a plan, clear the order, view collaborators, manage service type settings, delete; exiting saves automatically. Admins/editors import items, notes, people; team leaders only people from teams they lead. Web: Order tab "Add" → "Import template" (or Teams tab "Team actions" → "Import template") → choose template or recent plan → Include: "Items," "Notes," "Teams" (with "My"/"All") → "Import To" (check additional plans; current plan preselected) → "Submit." Mobile: Teams tab → plus → "Import Template" → pick → "Import."
